# Run Process on Andromeda HPC cluster

## AlphaFold 3

### Setup
- Container: `docker://chaunceyzhou/alphafold3` pulled with Singularity
- Model weights: downloaded from `https://storage.googleapis.com/alphafold3/af3.bin.zst`
- Input JSONs: generated by `make_jsons.py`

### Example input
JSON version 1:
```json
{
  "name": "100_Vascular_Endothelial_Growth_Factor_VEGF",
  "sequences": [
    {
      "rna": {
        "id": "A",
        "sequence": "GGGAGCC",
        "unpairedMsa": ""
      }
    },
    {
      "protein": {
        "id": "B",
        "sequence": "MNFLLSWVHWSLALLLY....",
        "unpairedMsa": "",
        "pairedMsa": "",
        "templates": []
      }
    }
  ],
  "modelSeeds": [
    42
  ],
  "dialect": "alphafold3",
  "version": 1
}
```
  #### Note:
   - Proteins need `"unpairedMsa": ""`, `"pairedMsa": ""`, and `"templates": []`.
   - RNA aptamers need `"unpairedMsa": ""`.
   - DNA aptamers need NONE.
    
### Running
```bash
sbatch af3_submit.sl
```
Key flags needed:
- `export XLA_FLAGS="--xla_disable_hlo_passes=custom-kernel-fusion-rewriter"` — fixes GPU compatibility
- `--flash_attention_implementation=xla` — required for cluster GPUs
- `--run_data_pipeline=false` — skips MSA database search

### Collecting Results
```bash
python collect_af3_results.py
```

## Boltz-2

### Setup
- Installed with `pip install "boltz[cuda]"` in a conda environment (Python 3.11). *Kept installing boltz-1 when I ran on my normal python version*
- Weights were downloaded automatically on first run
- Input YAMLs: generated by `make_yamls.py`
- **Code modification for RNA/DNA affinity predictions** was done in `schema.py` to allow DNA/RNA as affinity binders

### Example Input
```yaml
version: 1
sequences:
  - protein:
      id: A
      sequence: MNFLLSWVHWSLALLLYLHHAKWSQA...
  - rna:
      id: B
      sequence: GGCCGGUAGUCGCAUGGCCCAUCGCGCCCGG
properties:
  - affinity:
      binder: B
```

### Running
```bash
sbatch boltz_submit.sl
```

### Collecting Results
```bash
python collect_boltz_results.py
```
