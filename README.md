# Bento Aptamer Lab Challenge

Scripts and results from running AlphaFold 3 and Boltz-2 on aptamer-protein complexes from the UTexas Aptamer Database on Andromeda Cluster.

## Files

### Input Preparation
- `make_jsons.py` — reads UTexas Aptamer Database, fetches protein sequences from UniProt, generates AF3 JSON input files
- `make_yamls.py` — same as above but generates Boltz-2 YAML input files with affinity prediction properties

### AlphaFold 3
- `af3_submit.sl` — SLURM job script to run AF3 on all input JSONs
- `collect_af3_results.py` — extracts iPTM, pTM, ranking_score from AF3 outputs and matches to experimental Kd values
- `af3_results.csv` — AF3 predictions for 80 aptamer-protein complexes
- `af3_spearman.py` — calculates Spearman correlation between AF3 iPTM and experimental Kd

### Boltz-2
- `boltz_submit.sl` — SLURM job script to run Boltz-2 on all input YAMLs
- `collect_boltz_results.py` — extracts affinity_pred_value from Boltz-2 outputs and matches to experimental Kd values
- `boltz_results.csv` — Boltz-2 affinity predictions for 80 aptamer-protein complexes
- `boltz_spearman.py` — calculates Spearman correlation between Boltz-2 predicted affinity and experimental Kd

## Files Not Included
- **Input JSON/YAML files** — 80 input files generated by make_jsons.py and make_yamls.py
- **Model outputs** — AF3 and Boltz-2 prediction folders (large CIF and NPZ files)
- **Model weights** — AF3 (af3.bin) and Boltz-2 weights
- **Singularity container** — alphafold3.sif (pulled from docker://chaunceyzhou/alphafold3)
- **Dataset** — UTexas Aptamer Database available at https://zenodo.org/records/8387047

## Other Files
- `report.md` — Report containing workflow, Technical Issues, Limitations, and affinity analysis 
- `Runbook.md` — File describing run process for both models on Andromeda

## Dataset
UTexas Aptamer Database (1,415 sequences). Filtered to 80 complexes with valid aptamer sequences, protein targets found on UniProt, and experimental Kd values.

## Results
- AF3 Spearman correlation (iPTM vs Kd): r = -0.26, p = 0.02
- Boltz-2 Spearman correlation (affinity_pred_value vs Kd): r = -0.05, p = 0.67
